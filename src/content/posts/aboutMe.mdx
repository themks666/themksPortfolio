# Unity

Unity is one of the tools I am exploring for Game Development.

Using Unity and C#, I can work with:

* Game mechanics
* Player controllers
* Physics
* Animation
* UI
* Artificial Intelligence
* Environments
* Lighting
* Audio
* Scene management

A simple Unity script might look like:

```csharp
using UnityEngine;

public class Player : MonoBehaviour
{
    public float speed = 5f;

    void Update()
    {
        float x = Input.GetAxis("Horizontal");
        float z = Input.GetAxis("Vertical");

        Vector3 movement = new Vector3(
            x,
            0,
            z
        );

        transform.Translate(
            movement * speed * Time.deltaTime
        );
    }
}
```

Even a small script like this can become part of a much larger game system.
