# Building an Employee Management System with JavaScript

An Employee Management System is a practical project for learning how to build a complete CRUD-based web application.

Instead of simply displaying static information, the application allows users to create, view, update, and delete employee records.

In this project, we will build a simple Employee Management System using:

* HTML
* CSS
* JavaScript
* DOM Manipulation
* Local Storage

The project does not require a backend or database, which makes it a good project for understanding the fundamentals of web application development before moving to technologies such as Node.js, Express, MongoDB, or PostgreSQL.

---

# 1. What Is an Employee Management System?

An Employee Management System is an application used to store and manage employee information.

For example, an employee record might contain:

```text
Employee ID
Name
Email
Phone
Department
Position
Salary
```

Instead of maintaining these records manually, an application can provide a centralized interface for managing them.

A simple workflow looks like this:

```text
              Employee Management System

                       |
        +--------------+--------------+
        |              |              |
      Create          Read          Update
        |              |              |
        +--------------+--------------+
                       |
                     Delete
```

These four operations are commonly known as **CRUD**.

---

# 2. What Is CRUD?

CRUD stands for:

```text
C → Create
R → Read
U → Update
D → Delete
```

### Create

Add a new employee.

### Read

Display existing employees.

### Update

Modify an employee's information.

### Delete

Remove an employee.

CRUD is one of the most important concepts in application development because many real-world systems are based around these four operations.

# 9. Displaying Employees

We need a function that displays employees inside the table.

```js
function renderEmployees(list = employees) {

  employeeTableBody.innerHTML = "";

  list.forEach((employee) => {

    const row =
      document.createElement("tr");

    row.innerHTML = `
      <td>${employee.id}</td>

      <td>${employee.name}</td>

      <td>${employee.email}</td>

      <td>${employee.department}</td>

      <td>${employee.position}</td>

      <td>$${employee.salary}</td>

      <td>

        <button
          class="action-btn edit-btn"
          onclick="editEmployee(${employee.id})"
        >
          Edit
        </button>

        <button
          class="action-btn delete-btn"
          onclick="deleteEmployee(${employee.id})"
        >
          Delete
        </button>

      </td>
    `;

    employeeTableBody.appendChild(row);

  });

  employeeCount.textContent =
    employees.length;

}
```

The function loops through the employee array and generates a table row for every employee.

# 14. Create Employee Function

Let's create the function responsible for adding employees.

```js
function createEmployee(
  name,
  email,
  department,
  position,
  salary
) {

  const newEmployee = {

    id: Date.now(),

    name,

    email,

    department,

    position,

    salary

  };


  employees.push(
    newEmployee
  );


  saveEmployees();

  renderEmployees();

  employeeForm.reset();

  employeeModal.classList.add(
    "hidden"
  );

}
```

The `Date.now()` function gives us a number based on the current timestamp.

For a simple project, this can be used as a basic unique ID.

A production application would normally generate IDs on the server or database.

# 16. Updating Employees

Now create the update function.

```js
function updateEmployee(
  id,
  name,
  email,
  department,
  position,
  salary
) {

  const employee =
    employees.find(
      (employee) =>
        employee.id === id
    );


  if (!employee) {

  }


  employee.name = name;

  employee.email = email;

  employee.department =
    department;

  employee.position =
    position;

    salary;


  saveEmployees();

  renderEmployees();

  employeeForm.reset();

  employeeModal.classList.add(
    "hidden"
  );

}
```

Instead of creating a new object, we modify the existing employee.

# 17. Deleting Employees

Deleting an employee is straightforward.

```js
function deleteEmployee(id) {

  const confirmed =
    confirm(
      "Are you sure you want to delete this employee?"
    );


  if (!confirmed) {
    return;
  }


  employees =
    employees.filter(
      (employee) =>
        employee.id !== id
    );


  saveEmployees();

  renderEmployees();

}
```

The `filter()` method creates a new array containing every employee except the selected employee.

# 18. Searching Employees

A management system becomes much more useful when employees can be searched.

We already created:

```html
<input
  type="text"
  id="searchInput"
  placeholder="Search employees..."
>
```

Now we can listen for input:

```js
searchInput.addEventListener(
  "input",
  filterEmployees
);
```

Then create:

```js
function filterEmployees() {

  const searchTerm =
    searchInput.value
      .toLowerCase()
      .trim();

  const department =
    departmentFilter.value;


  const filtered =
    employees.filter(
      (employee) => {

        const matchesSearch =
          employee.name
            .toLowerCase()
            .includes(searchTerm) ||

          employee.email
            .toLowerCase()
            .includes(searchTerm) ||

          employee.position
            .toLowerCase()
            .includes(searchTerm);


        const matchesDepartment =
          department === "all" ||
          employee.department ===
            department;


        return (
          matchesSearch &&
          matchesDepartment
        );

      }
    );


  renderEmployees(filtered);

}
```

Now we can search for:

```text
John
john@example.com
Developer
Manager
```

# 20. Using Local Storage

Currently, our data exists only while the page is open.

If we refresh the browser, the data will disappear.

To solve this, we can use the browser's `localStorage`.

Saving data:

```js
function saveEmployees() {

  localStorage.setItem(
    "employees",
    JSON.stringify(employees)
  );

}
```

`localStorage` stores strings, so we use:

```js
JSON.stringify()
```

to convert our array into a string.

---

# 21. Loading Employees

When the application starts, we can retrieve the stored employees.

```js
function loadEmployees() {

  const storedEmployees =
    localStorage.getItem(
      "employees"
    );


  if (storedEmployees) {

    employees =
      JSON.parse(
        storedEmployees
      );

  }

}
```

`JSON.parse()` converts the stored string back into a JavaScript array.

We then call:

```js
loadEmployees();

renderEmployees();
```

The application can now remember employee records after refreshing the page.

  if (storedEmployees) {

    employees =
      JSON.parse(
        storedEmployees
      );

  }

}

function renderEmployees(
  list = employees
) {

  employeeTableBody.innerHTML =
    "";


  list.forEach((employee) => {

      <td>${employee.id}</td>

      <td>${employee.name}</td>

      <td>${employee.email}</td>

          class="action-btn delete-btn"
          onclick="deleteEmployee(${employee.id})"
        >
          Delete
        </button>

      </td>
    `;


    employeeTableBody.appendChild(
      row
    );

  });


  employeeCount.textContent =
    employees.length;

}

function updateEmployee(

function deleteEmployee(id) {

  const confirmed =
    confirm(

    return;

  employees =
    employees.filter(
      (employee) =>
        employee.id !== id

  saveEmployees();

  renderEmployees();

}

      createEmployee(
        name,
        email,

      "hidden"

// ==============================
// Search
// ==============================

function filterEmployees() {

  const searchTerm =
    searchInput.value
      .toLowerCase()
      .trim();


  const department =
    departmentFilter.value;


  const filtered =
    employees.filter(
      (employee) => {

        const matchesSearch =
          employee.name
            .toLowerCase()
            .includes(searchTerm) ||

          employee.email
            .toLowerCase()
            .includes(searchTerm) ||

          employee.position
            .toLowerCase()
            .includes(searchTerm);


        const matchesDepartment =
          department === "all" ||
          employee.department ===
            department;


        return (
          matchesSearch &&
          matchesDepartment
        );

      }
    );


  renderEmployees(filtered);

}

# 28. Why Use Local Storage?

Local Storage is useful for learning because it allows us to persist data without creating a backend.

For example:

```js
localStorage.setItem(
  "employees",
  JSON.stringify(employees)
);
```

The data stays in the browser even after refreshing the page.

However, Local Storage has important limitations.

It is not suitable for a real company-wide employee management system because:

* Data is stored only in the user's browser
* Multiple users cannot share the same data
* There is no centralized database
* Authentication is not provided
* Access control is not provided
* Sensitive employee information should not be stored this way

For a real application, we need a backend and database.
