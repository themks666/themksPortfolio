# Building a Simple Dino Game with JavaScript and HTML Canvas

Creating a game is one of the best ways to understand how programming concepts work together. Instead of learning JavaScript only through small exercises, we can use it to build something interactive.

In this project, we will build a simple **Dino Game** using **JavaScript and the HTML Canvas API**.

The game is inspired by the famous offline dinosaur game. The player controls a dinosaur that must jump over obstacles. As the player survives, the score increases and the game continues until the dinosaur collides with an obstacle.

We will build the game from scratch without using a game engine or external library.

## What We Will Build

Our game will contain:

* A dinosaur controlled with the keyboard
* Gravity and jumping physics
* Moving obstacles
* Collision detection
* A continuously increasing score
* Increasing game difficulty
* A game-over state
* Restart functionality
* A game loop using `requestAnimationFrame()`
* HTML Canvas rendering

The final project will look conceptually like this:

```text
+------------------------------------------+
|                    SCORE: 125             |
|                                          |
|        🦖                    🌵           |
|                              🌵          |
|__________________________________________|
```

The actual game will be rendered using Canvas.

# 1. What Is HTML Canvas?

HTML provides an element called `<canvas>` that allows JavaScript to draw graphics directly in the browser.

A basic canvas looks like this:

```html
<canvas id="gameCanvas"></canvas>
```

JavaScript can then access the canvas:

```js
const canvas = document.getElementById("gameCanvas");
const ctx = canvas.getContext("2d");
```

The `ctx` variable is the **2D rendering context**.

We can use it to draw:

* Rectangles
* Circles
* Lines
* Text
* Images
* Shapes
* Game objects

For example:

```js
ctx.fillStyle = "black";
ctx.fillRect(50, 50, 100, 100);
```

This draws a black rectangle.

Canvas is particularly useful for simple browser games because we can update and redraw the screen many times per second.

# 9. Adding Gravity

Gravity is one of the most important parts of the game.

Every frame, we increase the dinosaur's vertical velocity:

```js
dino.velocityY += dino.gravity;
```

Then we update its position:

```js
dino.y += dino.velocityY;
```

This creates falling motion.

However, the dinosaur should not fall through the ground.

We can check whether it reaches the ground:

```js
if (dino.y + dino.height >= ground.y) {
  dino.y = ground.y - dino.height;

  dino.velocityY = 0;

  dino.grounded = true;
}
```

Now the dinosaur stops at the ground.

# 10. Making the Dino Jump

When the user presses the Space key:

# 11. Creating Obstacles

Now we need something for the dinosaur to avoid.

We can represent obstacles with objects:

```js
let obstacles = [];
```

Each obstacle will contain:

```js
{
  x,
  y,
  width,

  speed
```

We can create an obstacle with a function:

```js
function createObstacle() {

  const height = 40 + Math.random() * 30;

  obstacles.push({
    x: canvas.width,

    width: 25,

```

The obstacle starts at:

```js
x: canvas.width
```

This means it appears at the right edge of the screen.

# 13. Moving the Obstacles

The obstacles need to move toward the dinosaur.

```js
function updateObstacles() {

  obstacles.forEach((obstacle) => {

    obstacle.x -= obstacle.speed;

  });

}
```

Every frame:

```text
Obstacle → → → → → 🦖
```

Since the obstacle moves left, it eventually passes the dinosaur.

---

# 14. Removing Old Obstacles

Once an obstacle leaves the screen, there is no reason to keep it in memory.

We can remove it:

```js
obstacles = obstacles.filter(
  (obstacle) => obstacle.x + obstacle.width > 0
);
```

This prevents the array from growing forever.

# 15. Spawning Obstacles

We don't want obstacles to appear continuously.

We can use a timer:

```js
let obstacleTimer = 0;

function spawnObstacles() {

  obstacleTimer++;

  if (obstacleTimer > 100) {

    createObstacle();

    obstacleTimer = 0;
  }

}
```

The timer increases every frame.

When it reaches `100`, a new obstacle is created.

# 16. Collision Detection

Collision detection determines whether two objects are touching.

For rectangles, we can use Axis-Aligned Bounding Box collision detection.

Create a function:

```js
function isColliding(a, b) {

  return (
    a.x < b.x + b.width &&
    a.x + a.width > b.x &&
    a.y < b.y + b.height &&
    a.y + a.height > b.y
  );

}
```

This checks whether the two rectangles overlap.

We can then check every obstacle:

```js
function checkCollisions() {

  for (const obstacle of obstacles) {

    if (isColliding(dino, obstacle)) {

      gameOver = true;

    }

  }

}
```

If the dinosaur touches an obstacle:

```js
gameOver = true;
```

# 21. Creating the Game Loop

The game loop is the heart of the game.

A game needs to repeatedly:

```text
Update
   ↓
Draw
   ↓
Update
   ↓
Draw
   ↓
Update
   ↓
Draw
```

We can use:

```js
requestAnimationFrame()
```

to create the loop.

A basic loop looks like this:

```js
function gameLoop() {

  update();

  draw();

  requestAnimationFrame(gameLoop);

}

gameLoop();
```

The browser calls the function repeatedly.

---

# 22. Updating the Game

Let's create an `update()` function.

```js
function update() {

  if (gameOver) {
    return;
  }


  dino.velocityY += dino.gravity;

  dino.y += dino.velocityY;

  if (dino.y + dino.height >= ground.y) {

    dino.y = ground.y - dino.height;

    dino.velocityY = 0;

    dino.grounded = true;

  }


  spawnObstacles();

  updateObstacles();


  checkCollisions();


  score += 0.1;


  increaseDifficulty();

}
```

This function contains the changing parts of the game.

# 26. Understanding the Physics

The jumping system is based on velocity and gravity.

When the player jumps:

```js
dino.velocityY = -14;
```

The dinosaur moves upward.

Every frame:

```js
dino.velocityY += dino.gravity;
```

Gravity makes the velocity increasingly positive.

For example:

```text
Frame 1: -14
Frame 2: -13.2
Frame 3: -12.4
Frame 4: -11.6
...
Frame 17: ~0
Frame 18: positive
Frame 19: falling
```

This creates a natural jump arc.

---

# 27. Why `requestAnimationFrame()`?

We could theoretically use:

```js
setInterval()
```

for a game loop.

However, `requestAnimationFrame()` is designed for browser animations.

```js
requestAnimationFrame(gameLoop);
```

It allows the browser to schedule rendering efficiently.

The general pattern is:

```js
function gameLoop() {

  update();

  draw();

  requestAnimationFrame(gameLoop);

}
```

This pattern is useful beyond this project.

Many JavaScript canvas games follow a similar architecture.

For example:

```text

├── player.js
├── obstacle.js
├── input.js
├── collision.js
```

Each module can have a specific responsibility.

For example:

```text
player.js
    ↓

    ↓
Obstacle generation

collision.js
    ↓
Collision detection

renderer.js
    ↓
```

This makes larger games easier to maintain.

# 39. Conclusion

The Dino Game is a simple but useful JavaScript project for learning game development.

We started with a basic HTML Canvas and gradually added:

```text
Canvas
  ↓
Player
  ↓
Gravity
  ↓
Jumping
  ↓
Obstacles
  ↓
Collision Detection
  ↓
Score
  ↓
Difficulty
  ↓
Game Over
  ↓
Restart
```

The most important concept is the **game loop**:

```js
function gameLoop() {

  update();

  draw();

  requestAnimationFrame(gameLoop);

}
```

Once this pattern becomes familiar, creating other browser games becomes much easier.

This project can also serve as a foundation for more advanced projects involving sprites, animation, sound, particles, levels, enemies, power-ups, and eventually dedicated game engines such as Unity.

The goal of a project like this is not simply to create a dinosaur that jumps over a cactus. It is to understand how **input, logic, physics, rendering, and game state work together to create an interactive application**.
